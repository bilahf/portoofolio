# Premium Portfolio

A premium personal portfolio website built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and a data-driven content structure.

## Install Dependencies

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

## Deploy To Vercel

1. Push this project to a Git repository.
2. Import the repository into [Vercel](https://vercel.com/).
3. Deploy with the default Next.js settings.

No additional configuration is required.

## Edit Portfolio Content

- Profile information: `data/profile.ts`
- Projects: `data/projects.ts`
- Skills: `data/skills.ts`
- Experience: `data/experience.ts`
- Education: `data/education.ts`
- Courses & Certifications: `data/certifications.ts`
- Achievements: `data/achievements.ts`
- Contact information: `data/contact.ts`

## Replace Images And Assets

Replace the placeholder files inside `public/images`:

- Profile photo: `public/images/profile`
- Project images: `public/images/projects`
- Company logos: `public/images/experience`
- University logos: `public/images/education`
- Certificate images: `public/images/certifications`
- Achievement images: `public/images/achievements`
- Favicon and OG assets: `public/images/icons`

Resume file:

- Replace `public/resume.pdf` with your real resume.
